# Cybersecurity Python Projects

Educational collection of beginner cybersecurity projects.

## Projects

1. Caesar Cipher Tool — encrypt/decrypt text using a shift value.
2. Image Encryption Tool — educational RGB pixel manipulation for reversible image transformation.
3. Password Strength Checker — evaluates length, letter case, numbers, and special characters.
4. Ethical Packet Sniffer — authorized IPv4 packet capture and analysis using Scapy.

All projects are intended for educational use on systems and networks where you have permission. They are not presented as production-grade security tools.
