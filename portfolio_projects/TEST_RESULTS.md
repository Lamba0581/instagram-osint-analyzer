# Test Results

The repository contains runnable educational implementations and representative output examples.

- Caesar Cipher: reversible encryption/decryption demonstrated with `Hello World` and shift `3`.
- Password Strength Checker: composition-based scoring with feedback; test example documented in OUTPUTS.md.
- Image Encryption: reversible RGB transformation using a key from 1-255; requires Pillow.
- Ethical Packet Sniffer: IPv4 capture and display of source/destination, protocol, ports, packet size, and limited printable payload preview; requires Scapy and authorized capture privileges.

No real private credentials, private traffic, or personal data are included in the output examples.
