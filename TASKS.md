# Cybersecurity Internship Tasks

## Task-01 — Caesar Cipher
Implemented text encryption/decryption using a shift value. Output is documented in `Task-01_Caesar-Cipher/OUTPUT.md`.

## Task-02 — Pixel Manipulation for Image Encryption
Implemented reversible RGB pixel manipulation. Output workflow is documented in `Task-02_Pixel-Manipulation-for-Image-Encryption/OUTPUT.md`.

## Task-03 — Password Complexity Checker
Implemented password length, uppercase, lowercase, number, and special-character checks with strength feedback. Output is documented in `Task-03_Password-Complexity-Checker/OUTPUT.md`.

## Task-04 — Simple Keylogger
Implemented a visible, consent-based keylogger simulator that records keys only inside its own application window. Output is documented in `Task-04_Simple-Keylogger/OUTPUT.md`.

## Task-05 — Network Packet Analyzer
Implemented authorized IPv4 packet capture and analysis with source/destination IP, protocol, ports, packet size, and limited payload preview. Output is documented in `Task-05_Network-Packet-Analyzer/OUTPUT.md`.

All tasks are educational projects. Use only on systems, accounts, images, and networks for which you have authorization.
